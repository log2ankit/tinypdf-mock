# Security

tinypdf-mock is a development tool that runs on your own machine. The README section
"What it does on your machine" lists everything it reads, writes and connects to.

If you find a way for a web page or another machine to control the server without the token,
to read files through it, or to make it send requests the person did not ask for, please
email support@tinypdf.in instead of opening a public issue. Include the version
(`npx tinypdf-mock --version`) and the steps. You will get a reply within a few days.
